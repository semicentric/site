# Display typefaces

Six self-hosted display faces, switchable via `data-font="<slug>"` on any ancestor
element. Each maps to `--font-display` in `app/globals.css`.

---

## zodiak

- **Family:** Zodiak
- **Foundry / designer:** Indian Type Foundry (Fontshare)
- **License:** Fontshare Free Font EULA (free for commercial use, self-hosting permitted)
- **Source:** https://www.fontshare.com/fonts/zodiak (`https://api.fontshare.com/v2/fonts/download/zodiak`)
- **Files:** `zodiak-regular.woff2` (400), `zodiak-bold.woff2` (700)
- **Why:** High-contrast Didone-adjacent editorial serif with sharp, unbracketed
  serifs and a tall, calm lowercase. Reads as a masthead, not a product.

## basteleur

- **Family:** Basteleur
- **Foundry / designer:** Keussel, published by Velvetyne Type Foundry
- **License:** SIL Open Font License 1.1
- **Source:** https://velvetyne.fr/fonts/basteleur/ (`https://gitlab.com/velvetyne/basteleur`)
- **Files:** `basteleur-moonlight.woff2` (400), `basteleur-bold.woff2` (700)
- **Why:** A strange, slightly medieval serif with flared stems and irregular
  terminals. Characterful without being decorative, and the Moonlight lowercase
  is unusually quiet for how odd it is.

## sligoil

- **Family:** Sligoil
- **Foundry / designer:** Ariel Martín Pérez, published by Velvetyne Type Foundry
- **License:** SIL Open Font License 1.1
- **Source:** https://velvetyne.fr/fonts/sligoil/ (`https://gitlab.com/velvetyne/sligoil`)
- **Files:** `sligoil-micro.woff2` (400), `sligoil-micro-medium.woff2` (500)
- **Why:** A humanist monospace built for a corporate-uncanny register: orderly,
  bureaucratic, faintly unsettling. Exactly the tone of a security firm that
  will not tell you what it does.

## bluu-next

- **Family:** Bluu Next
- **Foundry / designer:** Jean-Baptiste Morizot, published by Velvetyne Type Foundry
- **License:** SIL Open Font License 1.1
- **Source:** https://velvetyne.fr/fonts/bluu/ (`https://github.com/velvetyne/BluuNext`)
- **Files:** `bluu-next-bold.woff2` (mapped to 400; the family's text weight)
- **Why:** A Renaissance/Jenson-flavored revival with heavy old-style stress and
  calligraphic entry strokes. Institutional and old in the way a chartered
  company is old.

## cabinet-grotesk

- **Family:** Cabinet Grotesk
- **Foundry / designer:** Indian Type Foundry (Fontshare)
- **License:** Fontshare Free Font EULA (free for commercial use, self-hosting permitted)
- **Source:** https://www.fontshare.com/fonts/cabinet-grotesk (`https://api.fontshare.com/v2/fonts/download/cabinet-grotesk`)
- **Files:** `cabinet-grotesk-regular.woff2` (400), `cabinet-grotesk-bold.woff2` (700)
- **Why:** A display grotesque with tight apertures, a low waistline and slightly
  squared bowls. Neutral at a glance, wrong in the right ways up close.

## departure-mono

- **Family:** Departure Mono
- **Foundry / designer:** Helena Zhang
- **License:** SIL Open Font License 1.1
- **Source:** https://departuremono.com (`https://github.com/rektdeckard/departure-mono`)
- **Files:** `departure-mono-regular.woff2` (400)
- **Why:** A bitmap-derived technical mono with visible pixel logic in the
  outlines. Machine-made rather than styled, which suits a page that is mostly a
  name and an address.
